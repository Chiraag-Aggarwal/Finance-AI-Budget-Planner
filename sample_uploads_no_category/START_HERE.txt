in total. None has a Category column. All dates are August-October 2026 and use
day/month/year. Every file uses a different set of dates, descriptions and amounts.

HOW TO TEST
Use a demo account. In Monthly budget, upload one file, keep day-first dates,
read the preview, review the suggested categories, then add the selected rows.
The preview shows 25 rows per page, so use Next to see the rest.
After saving, select August, September or October 2026 to see that month's entries.

The importer reads dates, amounts and income/expense type. The category helper
then uses the description to suggest missing categories. If it is uncertain,
Other or Other income is expected. You can change the category before saving.
These files do not measure the model's real-world accuracy.
